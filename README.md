# ترابری 🚚

وب‌اپ مسیریابی چندمقصدی و ردیابی راننده‌ها برای حمل بار از یک شهر به چند مقصد.

**آدرس اپ:** https://saman882.github.io/tarabari/

## امکانات
- **بهترین مسیر با اولویت:** مقصدها را وارد کنید؛ کوتاه‌ترین مسیر روی جاده محاسبه می‌شود. مقصدی که «اولویت ۱» دارد همیشه اول تحویل می‌شود (حتی اگر در نزدیک‌ترین مسیر سوم باشد)، بعد اولویت ۲ و… و بقیه به ترتیب کوتاه‌ترین مسیر. محاسبه دقیق است (تا ۱۵ مقصد، برنامه‌ریزی پویا).
- **برگه‌ی چیدن بار:** ترتیب تحویل + ترتیب چیدن در ماشین (بار مقصد آخر ته ماشین).
- **شروع حرکت:** روز حرکت، مسیر از موقعیت فعلی راننده با همان مقصدها و اولویت‌ها دوباره محاسبه می‌شود؛ اگر ترتیب عوض شد هشدار می‌دهد.
- **تحویل مرحله‌ای:** مقصد فعلی ← «رسیدم» (خودکار در ۲۰۰ متری) ← «تحویل دادم» ← مقصد بعدی. دکمه‌ی مسیریابی با نشان/بلد/گوگل‌مپ/ویز.
- **چند راننده:** هر راننده حساب جدا و سفرها/مسیرهای خودش.
- **پنل سرپرست:** نقشه‌ی زنده‌ی همه‌ی راننده‌ها (GPS)، فروشگاه‌ها، بهترین مسیر (آبی)، مسیر طی‌شده (قرمز)، مسیر چیدمان اولیه (بنفش خط‌چین)، زمان حرکت، زمان تخمینی/واقعی رسیدن و تحویل هر مقصد و میزان تأخیر.

## اولین استفاده
1. اپ را باز کنید. اولین بار فرم «ساخت حساب سرپرست» نمایش داده می‌شود.
2. در پنل سرپرست ← «راننده‌ها» برای هر راننده نام کاربری و رمز بسازید.
3. در «فروشگاه‌ها» محل فروشگاه‌ها و انبار را ثبت کنید (جستجو یا کلیک روی نقشه).
4. سفر بسازید (سرپرست برای راننده، یا خود راننده).

## ساختار فنی
- `src/` — وب‌اپ (JavaScript + Vite + Leaflet، نقشه OpenStreetMap)
- `src/optimize.js` — الگوریتم ترتیب بهینه با محدودیت اولویت (Held-Karp + 2-opt برای تعداد زیاد)
- `supabase/migrations/` — جداول و دسترسی‌ها (RLS)
- `supabase/functions/admin` — ساخت/مدیریت حساب‌ها
- `supabase/functions/geo` — پراکسی مسیریابی OSRM و جستجوی آدرس
- انتشار خودکار روی GitHub Pages با هر push (`.github/workflows/deploy.yml`)

## نکته‌ها
- ثبت GPS وقتی است که صفحه‌ی سفر در گوشی راننده باز باشد (اپ جلوی خاموش شدن صفحه را می‌گیرد). اگر اینترنت قطع شود نقاط ذخیره و بعداً ارسال می‌شوند.
- اجرای محلی: `npm install && npm run dev`
